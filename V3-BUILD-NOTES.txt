WORD SCAVENGER V3 — MARBLE BAG BUILD

What changed
- Added js/marble-bag.js as a separate in-memory bag engine.
- Integrated true draw-without-replacement bags and independent replenishment.
- Added projected-board safeguards for vowel/consonant, common/uncommon, and normal/bonus balance.
- Connected initial board generation, ordinary refills, Bomb replacements, Randomize, and Long Word Bonus to the new rules.
- Preserved the existing three-flip Randomize animation; only the final replacement consumes a letter-bag draw.
- Long Word Bonus uses weighted assignment with replacement and does not consume bonus-bag entries. Wild Letter tiles remain unbonused.
- Added MARBLE-BAG-SPEC.md and tests/marble-bag.test.js.

Bag visualization
- Open marble-bag-preview.html through VS Code Live Server to inspect the real engine.
- Use “Draw next tile” to step through generation and inspect remaining entries and the latest draw path.
- Use “Generate full board” to test the 5x5 safeguards.
- Use “Reset bags and board” to start a fresh simulation.

Validation performed
- JavaScript syntax checks passed for the Marble Bag engine and integration files.
- All existing tests/*.test.js scripts passed, including the new Marble Bag tests.
- A 10,000-board simulation produced no violations of the initial vowel (8–12), uncommon consonant (2–5), or bonus tile (5–10) bounds.

Notes
- Bag state is in memory and resets for each new round; no localStorage persistence was added.
- The bonus-tile tolerance of 5–10 per 25-tile board is an initial tuning range, not a permanently fixed balance target.

v3.05 hotfix (2026-10-26): Restored board tile interaction by fixing an over-broad pointer guard. Board tiles are buttons, so the previous guard accidentally rejected all board tile pointer-down events. Automated syntax and test suites passed; live browser/device testing remains pending.


v3.06 hotfix (2026-10-26): Added a picker-level fresh pointer-down gate to prevent the Wild Letter target-tile tap's trailing click from choosing a letter. Timers continue during tile targeting and pause only while the letter picker is open, resuming according to their prior running state. Updated changelog and authoritative scoring/timer rules to restore the v3.05 source-aligned timer rewards and 180-second cap. All six Node test suites pass; live browser/mobile touch testing remains pending.

v3.07 (2026-10-26): Added bounded trajectory-aware tile resolution for ordinary drag selection. Samples are resolved against tile rectangles cached by current board index, tolerate a narrow gap around tile edges, prefer valid neighboring tiles, reject distant jumps, and preserve backtracking to previously selected tiles. Added deterministic resolver tests and bumped the PWA cache to v12. Syntax and all six Node test suites pass; browser and Android thumb-drag verification remain pending.

v3.07.7 focused flip artifact fix (2026-10-30)
- Root cause: `.tile.bonus-hit::after` created a dark BONUS label while `.tile::after` was the new inset-edge treatment. The pseudo-element selector conflict made the label appear as a dark rectangular face during tile flip/bonus feedback.
- Removed the conflicting label and Style 2 override; retained bonus outline/glow and the inset edge.
- Restored the original 90-degree flip midpoint and removed v3.07.6 backface tweaks.
- Automated tests and syntax checks run; live browser visual confirmation still required.

v3.07.8 local vowel balancing (2026-10-30)
- Added the proposed local 3×3 vowel safeguard to the existing Marble Bag System: each of the four corner blocks and center block normally stays between 2 and 6 vowels inclusive.
- Initial board generation validates all five overlapping blocks as tiles are generated; ordinary word refills validate only blocks containing the replacement position.
- Randomize filters replacement candidates against the affected local block(s) when at least one eligible letter can satisfy the constraint.
- Rotate and Swap remain pure tile transformations. Bomb refill generation explicitly bypasses local balancing to preserve its power-specific behavior; Wild Letter remains a special tile and is not treated as a normal bag draw by local checks.
- Candidate retries are bounded to 20. Rejected candidate draws restore all bag entries, draw counts, replenishment counts, and last-draw metadata; after retry exhaustion, the local constraint relaxes for that draw only. Existing global balancing rules remain unchanged.
- Added deterministic coverage for the five block definitions, overlapping center membership, initial board constraints, bounded fallback/bag accounting, and Randomize filtering.
- JavaScript syntax checks and all six Node test suites pass. Browser visual and Android interaction tests remain pending.
- Initial board creation additionally retries the complete board up to 12 times when any final 3×3 block falls outside the 2–6 range; each full-board retry resets all independent bags. After the bounded board retries, gameplay starts with the final generated board rather than hanging.
